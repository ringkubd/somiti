# Somiti Manager — সম্পূর্ণ প্রজেক্ট পরিকল্পনা

**তৈরি:** 2026-08-09  
**শাখা:** `mobile-app`  
**ডিফল্ট শাখা:** `main`

## 📊 বর্তমান অবস্থা সারসংক্ষেপ

### ব্যাকএন্ড (Laravel 12) — ✅ মূলত সম্পূর্ণ
- ডাবল-এন্ট্রি অ্যাকাউন্টিং (`AccountingService` + `ChartOfAccounts` + `JournalEntry`)
- অডিট রিপোর্টের সমস্যাগুলো সমাধান হয়েছে: লোন অবজার্ভার ঠিক, অ্যাপ্রুভাল অবজার্ভার সরলীকৃত, লেজার অপরিবর্তনীয়
- অনুমোদন ব্যবস্থা (deposit, loan, investment, FDR, share, share-transfer, repayment, withdrawal, penalty, dividend)
- মাল্টি-টেন্যান্ট (somiti) স্কোপ, পারমিশন, পলিসি
- চ্যাট, নোটিফিকেশন, পুশ টোকেন, রিসিট
- CMS (ব্লগ, পেজ, SEO, নেভিগেশন, বিজ্ঞাপন) + সুপার অ্যাডমিন

### ওয়েব ফ্রন্টএন্ড (Inertia + React) — ✅ প্রায় সম্পূর্ণ
- সমস্ত মডিউলের পেজ তৈরি (Deposits, Loans, Investments, FDRs, Shares, Transfers, Approvals, BankAccounts, FinancialYears, Reports, Dividends, Penalties, Repayments, Withdrawals)
- সুপার অ্যাডমিন প্যানেল (ব্লগ, CMS, SEO, নেভিগেশন, পেজ, বিজ্ঞাপন, ব্যবহারকারী)
- লেআউট: AppLayout, breadcrumbs, Tailwind, Radix UI

### মোবাইল অ্যাপ (Expo + React Native) — ⚠️ আংশিক
- **সম্পূর্ণ:** অথ, ড্যাশবোর্ড, ডিপোজিট, লোন, শেয়ার, ট্রান্সফার, ব্যাংক অ্যাকাউন্ট, চ্যাট, অনুমোদন, রিপোর্ট, সেটিংস, ফাইন্যান্সিয়াল ইয়ার, প্রোফাইল, নোটিফিকেশন, লক স্ক্রিন, বায়োমেট্রিক
- **নতুন যোগ:** ডিভিডেন্ড, পেনাল্টি, রিপেমেন্ট, উইথড্রয়াল, মেম্বার, রিসিট (নেভিগেটরে নিবন্ধিত)
- **অসম্পূর্ণ/প্লেসহোল্ডার:** কিছু ডিটেইল স্ক্রিন, কিছু ক্রিয়েট স্ক্রিন যাচাই বাকি

## 🎯 প্রজেক্ট লক্ষ্য
একটি সমবায় সমিতি ব্যবস্থাপনা সিস্টেম যা:
1. সদস্য সঞ্চয়, ঋণ, শেয়ার, বিনিয়োগ, FDR পরিচালনা করে
2. ডাবল-এন্ট্রি বুককিপিং দিয়ে আর্থিক স্বচ্ছতা নিশ্চিত করে
3. মাল্টি-টেন্যান্ট (একাধিক সমিতি) সমর্থন করে
4. ওয়েব + মোবাইল উভয় প্ল্যাটফর্মে সম্পূর্ণ
5. বাস্তব-সময় চ্যাট ও নোটিফিকেশন

## 📋 সম্পূর্ণতার পরিকল্পনা (ফেজ অনুসারে)

### ফেজ ১: মোবাইল অ্যাপ বাগ ফিক্স ও সম্পূর্ণতা (জরুরি)
1. **নতুন স্ক্রিন যাচাই** — Dividends, Penalties, Repayments, Withdrawals, Members স্ক্রিনগুলো API এর সাথে সঠিকভাবে সংযুক্ত কিনা নিশ্চিত করুন
2. **ডিটেইল স্ক্রিন যোগ** — Investments, FDRs, BankAccounts, ShareTransfers, Dividends, Penalties, Repayments, Withdrawals এর জন্য ডিটেইল স্ক্রিন যাচাই/তৈরি
3. **ড্যাশবোর্ড কুইক অ্যাকশন আপডেট** — নতুন মডিউলগুলো (dividends, penalties, repayments, withdrawals, members) ড্যাশবোর্ড থেকে অ্যাক্সেসযোগ্য করুন
4. **ত্রুটি ব্যবস্থাপনা** — সমস্ত স্ক্রিনে লোডিং স্টেট, ত্রুটি হ্যান্ডলিং, খালি অবস্থা উন্নত করুন
5. **API ক্লায়েন্ট উন্নতি** — রিফ্রেশ টোকেন, পুনঃচেষ্টা লজিক, বাস্তব-সময় আপডেট (WebSocket/Pusher)

### ফেজ ২: ব্যাকএন্ড শক্তিশালীকরণ
1. **ঋণ EMI/সময়সূচি** — ঋণ পরিশোধের সময়সূচি গণনা, সুদ গণনা স্বয়ংক্রিয় করুন
2. **FDR পরিণতি** — মেয়াদ উত্তীর্ণ ওয়ার্কফ্লো, লাভ রেকর্ডিং
3. **বিনিয়োগ রিটার্ন** — মেয়াদ উত্তীর্ণ ও লাভ/ক্ষতি রেকর্ডিং
4. **আর্থিক বছর বন্ধ** — ব্যালেন্স ক্যারি-ফরোয়ার্ড, লেজার লক
5. **টেন্যান্ট লেখা বৈধতা** — সমস্ত লেখা অপারেশনে somiti_id যাচাই
6. **সাবস্ক্রিপশন/বিলিং** — (ঐচ্ছিক, ভবিষ্যতে)

### ফেজ ৩: ওয়েব ফ্রন্টএন্ড সম্পূর্ণতা
1. **বাকি Blade → Inertia মাইগ্রেশন** — সমস্ত ভিউ ইনার্শিয়া/রিঅ্যাক্টে রূপান্তর
2. **ইমেল যাচাই** — রুট সেটআপ ও পুনঃসক্রিয়
3. **সদস্য আমন্ত্রণ** — ইমেল/SMS আমন্ত্রণ ব্যবস্থা
4. **দ্বি-ফ্যাক্টর অথ** — সম্পূর্ণ সেটআপ
5. **প্রতিবেদন প্রসার** — ব্যালেন্স শিট, সদস্য বিবৃতি, তহবিল সারসংক্ষেপ

### ফেজ ৪: উৎপাদন প্রস্তুতি
1. **পরীক্ষা কভারেজ** — আর্থিক অনুমোদন লজিকের জন্য পেস্ট টেস্ট বৃদ্ধি
2. **ডিপ্লয়মেন্ট** — ডকার, CI/CD পাইপলাইন
3. **নিরাপত্তা** — হার্ডেনিং, রেট লিমিট, অডিট লগ
4. **পর্যবেক্ষণ** — লগিং, ত্রুটি ট্র্যাকিং, পারফরম্যান্স
5. **ডকুমেন্টেশন** — API ডকস, ব্যবহারকারী গাইড

## 🤖 এজেন্ট কনফিগারেশন

নিম্নলিখিত এজেন্টগুলো সম্পূর্ণতার কাজে ব্যবহারের জন্য কনফিগার করা হবে। প্রতিটি `somiti` এজেন্ট নামের অধীনে প্রজেক্ট-নির্দিষ্ট নির্দেশিকা সহ।

### ১. ব্যাকএন্ড ডেভেলপার এজেন্ট
**নাম:** `somiti-backend`  
**ভূমিকা:** Laravel ব্যাকএন্ড — মডেল, মাইগ্রেশন, কন্ট্রোলার, অবজার্ভার, সার্ভিস, API রুট  
**দায়িত্ব:**
- ঋণ EMI/সময়সূচি গণনা ও পরিশোধ ট্র্যাকিং
- FDR/বিনিয়োগ পরিণতি ও লাভ রেকর্ডিং
- আর্থিক বছর বন্ধ ও ব্যালেন্স ক্যারি-ফরোয়ার্ড
- টেন্যান্ট লেখা বৈধতা
- পরীক্ষা কভারেজ বৃদ্ধি (পেস্ট)
- API ডকুমেন্টেশন

### ২. ওয়েব ফ্রন্টএন্ড ডেভেলপার এজেন্ট
**নাম:** `somiti-web`  
**ভূমিকা:** Inertia + React ওয়েব ফ্রন্টএন্ড  
**দায়িত্ব:**
- বাকি Blade টেমপ্লেট ইনার্শিয়া/রিঅ্যাক্টে রূপান্তর
- ইমেল যাচাই ও দ্বি-ফ্যাক্টর অথ UI
- সদস্য আমন্ত্রণ ব্যবস্থা
- প্রতিবেদন পেজ প্রসার
- ওয়েব UI পরিমার্জন ও সামঞ্জস্য

### ৩. মোবাইল ডেভেলপার এজেন্ট
**নাম:** `somiti-mobile`  
**ভূমিকা:** Expo + React Native মোবাইল অ্যাপ  
**দায়িত্ব:**
- নতুন স্ক্রিন (Dividends, Penalties, Repayments, Withdrawals, Members) সম্পূর্ণতা ও API সংযোগ যাচাই
- ডিটেইল স্ক্রিন তৈরি/সম্পূর্ণতা
- ড্যাশবোর্ড কুইক অ্যাকশন আপডেট
- ত্রুটি ব্যবস্থাপনা ও লোডিং স্টেট উন্নত
- বাস্তব-সময় আপডেট (WebSocket/Pusher) একীকরণ
- পুশ নোটিফিকেশন পরীক্ষা

### ৪. ডিপ্লয়মেন্ট/ডেভঅপস এজেন্ট
**নাম:** `somiti-deploy`  
**ভূমিকা:** ডিপ্লয়মেন্ট, CI/CD, অবকাঠামো  
**দায়িত্ব:**
- ডকারাইজেশন (Laravel + MySQL + Nginx)
- CI/CD পাইপলাইন (GitHub Actions)
- পরিবেশ কনফিগারেশন (.env, রহস্য ব্যবস্থাপনা)
- ডিপ্লয় স্ক্রিপ্ট
- পর্যবেক্ষণ ও লগিং সেটআপ

### ৫. QA/পরীক্ষা এজেন্ট
**নাম:** `somiti-qa`  
**ভূমিকা:** গুণমান নিশ্চিত ও পরীক্ষা  
**দায়িত্ব:**
- পেস্ট টেস্ট কভারেজ বৃদ্ধি (বিশেষত আর্থিক লজিক)
- ইন্টিগ্রেশন টেস্ট
- নিরাপত্তা পরীক্ষা (অনুমোদন, টেন্যান্ট বিচ্ছিন্নতা)
- ক্রস-প্ল্যাটফর্ম পরীক্ষা (ওয়েব + মোবাইল)
- পরিবেশন পরীক্ষা
